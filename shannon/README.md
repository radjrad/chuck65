# Shannon at 37: The Grand Tour

Single-file birthday game, built from the chuck65 engine. Everything lives in
`index.html`. Live at <https://radjrad.github.io/chuck65/shannon/> once merged
to `main`.

## Photos

All slots are filled. To swap one, replace the file with the same name
(JPEG, about 1600px on the long side keeps the page fast on phones).

## Editing the words

Open `index.html` and find the `1. CONTENT` section near the top of the script.
Every question, answer, reaction, caption and game line is plain text there.
Nothing below that section needs to change for copy edits.

Keyboard on a TV or laptop: Enter/Space activates, arrows move, 1-4 pick an
answer, F = fullscreen, R = restart, S = sound. On a phone everything is tap.
